================================================
  合并转发搜索 · 一键安装包
================================================

【装之前，只要确认一件事】

  电脑上已经装了 QQ（新版 NT 界面，蓝白圆角图标那个）。
  没装的话先去 https://qq.qq.com 下载安装，登录一次，再回来。

  别的都不用管：
    - 不用装 Node.js
    - 不用另外下载 LiteLoader
    - 不用改系统设置
  安装包是离线的，加载器和插件都在里面，不联网也能装。


【怎么装】

  单文件版（推荐，就一个 .bat，不用解压）：
    双击  合并转发搜索-一键安装.bat
    跟着提示走，大约 1 分钟。中途会问你「现在打开 QQ？」。

  如果双击被拦住了：
    弹「Windows 已保护你的电脑」→ 点「更多信息」→「仍要运行」
    或者右键文件 → 属性 → 最下面勾「解除锁定」→ 确定 → 再双击
    这是 Windows 对"网上下载的 bat"的例行拦截，不是文件有毒。

  如果杀毒软件报毒 / 直接删掉了文件：
    自解压 bat 里塞了一大段编码数据，容易被误判。
    把它加进信任区，或者改用下面的文件夹版。

  文件夹版（上面的不好使就用这个，最稳）：
    1. 把 zip 整个解压出来（不要直接在压缩包里双击）
    2. 双击  install.bat
    3. 按提示走

  QQ 装在 C:\Program Files 里的，安装时会弹一次管理员授权，
  点「是」就行。脚本会自己提权，不用你手动右键。


【装完为什么搜不到东西】

  这是正常的，不是坏了。

  插件需要先把聊天记录里的卡片"读一遍"存到本地，才能搜。
  刚装完索引是空的。

  做这一步：
    1. 在 QQ 里打开一个有合并转发卡片的群（先让它加载出来）
    2. 按 Alt + S 打开搜索框
    3. 点右下角「扫描历史」，弹确认就点确定
    4. 等它跑完（几分钟，取决于你聊天量的多少）

  第一次点扫描，它会问你"要不要打开内容补全模式"——
  点确定就行。那是"允许插件去读历史消息"的开关，只影响插件，不碰 QQ 设置。

  扫一次会把你**所有有本地缓存的会话**都过一遍，不用一个个群去点。
  但没打开过的群，本地还没有聊天记录，扫不到 ——
  得先进那个群看几眼（让它加载出来），再扫一次。

  跑完之后就能搜了。
  之后新收到的卡片会自动收录，不用再手动扫。


【全新电脑 / 刚登录的 QQ，特别注意】

  QQ 的聊天记录是登录之后慢慢从服务器往本地拉的，
  不是一登录就全在硬盘上。

  所以在新电脑上刚登上 QQ，那个群可能还没有本地记录，
  这时候点「扫描历史」会扫到 0 条 —— 不是插件坏了。

  正确做法：
    先进那个群，往上翻几屏聊天记录，让它加载出来，
    再点「扫描历史」，就能扫到卡片了。


【装到哪里了】

  插件加载器和插件都装在：

    C:\Users\你的用户名\AppData\Local\LiteLoaderQQNT

  这个位置的好处：
    - 不碰 C 盘系统目录
    - 卸载时直接删掉就行
  唯一动到 QQ 的地方，是给它加了一个启动入口文件，
  原配置备份在同目录的 package.json.fs-backup。

  你的搜索索引在这里：

    ...\LiteLoaderQQNT\data\forward-search\records.jsonl

  注意：这是明文。想清理就删这个文件夹。


【怎么用】

  Alt + S           打开 / 关闭搜索面板
  拖标题栏          移动面板
  右上角 ×          收起面板
  顶部左边两个按钮   切换「本群 / 全部」
  顶部右边按钮       切换「相关度 / 时间」排序
  不输入直接打开     按时间倒序显示最近收录的卡片
  点结果             直接跳到那条消息所在位置

  点完结果面板会收成右下角一条，不挡聊天。
  再按 Alt + S 重新展开。


【怎么卸载】

  文件夹版：双击  uninstall.bat
  单文件版：重新双击安装包，会检测到已安装并引导你卸载

  它会把 QQ 还原成装之前的样子，并删掉加载器和索引。
  你的聊天记录不受任何影响（都在腾讯服务器和 QQ 自己的数据里）。


【出问题了】

  装完 QQ 打不开？
    跑一遍卸载，QQ 立刻恢复。

  装了但 Alt + S 没反应？
    QQ 设置 → LiteLoaderQQNT → 插件列表，
    看 forward-search 是不是启用状态。

  QQ 更新之后插件不见了？
    QQ 升级会装进一个新的版本目录，入口是那个目录里的原版文件，
    所以我们改过的那份就没被用上。这不是装坏了。
    重新双击一次安装包，选「1 重新安装」就行，索引不会丢。

  提示"没有权限"？
    右键  install.bat / 安装包  → 以管理员身份运行。

  面板出来了但列表空的？
    看上面「装完为什么搜不到东西」那一段。


【说明】

  这是给 LiteLoaderQQNT 用的插件，安装包自带加载器，
  不用你自己再去下载。

  LiteLoaderQQNT 官方说 QQ 可能会把这类工具当作外挂，
  有封号风险。建议先拿小号试。

  本项目仅供技术学习研究使用。
